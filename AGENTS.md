# Prism — agent guide

Prism is a **macOS 26+ IPTV app** (Xtream Codes, M3U, XMLTV EPG) whose design replicates the
**Apple TV app for Mac** (macOS 26 "Liquid Glass" generation), adapted to IPTV. iOS comes later.
Focus: pixel-level Apple fidelity, fluid animations, performance on huge catalogs (100k+ items).

UI language: **French** (strings written directly in French in code).

## Layout

```
App/                       Thin Xcode app target (generated by XcodeGen from project.yml)
Packages/PrismKit/         All code lives here (SwiftPM, swift-tools 6.2, macOS 26, Swift 6)
  Sources/PrismCore/       Models, title normalizer, M3U/XMLTV parsers, Xtream + TMDB clients (no UI)
  Sources/PrismData/       Catalog builder/grouping, search index, stores (sources, keychain, library,
                           disk caches), repositories (catalog refresh, EPG, details), demo/preview data
  Sources/PrismDesign/     Design system: tokens, glass buttons, cards, shelves, hero, image pipeline, logo
  Sources/PrismPlayer/     Playback engines (AVFoundation + VLCKit) and the Apple TV–style player UI
  Sources/PrismUI/         App screens: shell/sidebar, home, live/guide, movies, series, detail,
                           search, library, onboarding, settings
Tools/                     Scripts (icon rendering, snapshots…)
design/                    Local design references (gitignored screenshots)
```

Dependency graph: `PrismCore ← PrismData ← PrismUI`, `PrismDesign ← PrismUI`, `PrismPlayer ← PrismUI`.
PrismDesign and PrismPlayer do **not** import PrismCore.

Concurrency: PrismDesign/PrismPlayer/PrismUI use `defaultIsolation(MainActor)`. PrismCore/PrismData are
nonisolated by default — use actors / `@concurrent` for heavy work (parsing, grouping, indexing),
`Sendable` value types everywhere. Upcoming features enabled: NonisolatedNonsendingByDefault,
InferIsolatedConformances, ExistentialAny, MemberImportVisibility.

## Commands

```sh
cd Packages/PrismKit
swift build --target <Target>                     # fast per-module build
swift test --filter PrismCoreTests                # Swift Testing
# Parallel agents: use a private scratch path to avoid lock contention:
swift build --target PrismCore --scratch-path .build/agent-core
xcodegen generate && xcodebuild -project Prism.xcodeproj -scheme Prism -destination 'platform=macOS' build
```

Never run the GUI app or take screen captures without the user's consent (the Mac is in use).
Visual checks are done offscreen with the snapshot harness (`PrismUITests` / `Tools/`).

## Conventions

- Swift 6, `@Observable` models, `@State` owned at the right level, `@Environment` for app-wide models.
- Value-type models from `PrismCore/Models` are the shared contract — extend, don't break.
- No force unwraps on external data. IPTV data is dirty: every field may be missing, a number as
  string, an empty string, or garbage.
- Lazy containers (`LazyHStack`/`LazyVGrid`) for every list of content; stable identities;
  images always downsampled to their display size through the shared `ImagePipeline`.
- Never block the main thread with parsing/IO. Debounce search (≈150 ms).
- Respect Reduce Motion (`@Environment(\.accessibilityReduceMotion)`).
- Tests: Swift Testing (`import Testing`, `@Test`, `#expect`). Fixtures under `Tests/*/Fixtures`.

## Apple TV (macOS) design spec — source of truth

References: `design/references-appletv-mac/*.png` (real Apple TV app on macOS 27, captured
2026-11-21) and Mobbin Apple TV iOS screens. Measurements below are in points.

### Window & shell
- Default window 1440×900, min 1100×700. Unified, hidden title; traffic lights over the sidebar.
- `NavigationSplitView` sidebar (system Liquid Glass sidebar), width ≈ 220. Content hero images
  extend **under** the sidebar with `.backgroundExtensionEffect()`.
- Sidebar items (SF Symbols, 13 pt, blue accent for icons, selected row = filled accent capsule):
  `Rechercher` (magnifyingglass), `Accueil` (house), `TV en direct` (play.tv),
  `Films` (film), `Séries` (tv). Section **Bibliothèque**: `Ma liste` (plus.circle → list),
  `Chaînes favorites` (star), `Historique` (clock.arrow.circlepath). Section **Sources**: one row per
  source with a tinted circular monogram + status, and `Ajouter une source…`. Bottom: profile row
  (monogram avatar 28 pt + name, 13 pt semibold) opening Settings.
- Content horizontal margin: **40**. Vertical gap between shelves: **36**.
- Custom in-content navigation stack (push = slide from trailing + fade, 0.35 s smooth spring),
  back = glass circle button 32 pt top-left (`chevron.left`), ⌘[ shortcut. Underlying pages keep
  their scroll position.
- Top-right of pages: glass circle buttons 32 pt (`speaker.slash`, `arrow.up.left.and.arrow.down.right`,
  `square.and.arrow.up`). When scrolled past the hero, a soft top bar appears with the page title
  (13 pt semibold) — use `scrollEdgeEffectStyle(.soft)`/material.

### Typography (SF Pro)
- Hero title text (when no logo image): 56–64 bold, tracking −1.5, white, max 2 lines, `.minimumScaleFactor`.
- Shelf header: 19 bold + `chevron.right` 15 semibold secondary, clickable ("Continuer >").
  Optional subtitle 13 regular secondary.
- Hero metadata line: 13 medium, white 85 %: `[source glyph] Série TV · Thriller · Mystery [rating badge]`.
- Hero description: 13 regular, white 80 %, 2 lines, followed by a `PLUS` pill (10 bold, white
  on white 20 % capsule) that expands the text.
- Tech line: `2022 · 57 min` 12 medium + badges.
- Card captions: 12 semibold white; card metadata 11 medium white 70 %.
- Episode card: `ÉPISODE 1` 10 semibold caps secondary, title 13 semibold, synopsis 11 regular 3 lines.

### Badges
Small rounded rect (radius 3, height 14, horizontal padding 4, 9 bold): outlined (1 pt white 70 %)
for `CC`, `SDH`, `AD`, `VOSTFR`, `MULTI`; filled (white 80 % bg, black text) for `4K`, `HD`, `FHD`, `HDR`.
Rating/age as circled glyph (e.g. `16+` in a 14 pt circle stroke). Live: red capsule `EN DIRECT`.

### Buttons
- Primary: white capsule, height 40, horizontal padding 24, 15 semibold black, leading SF Symbol
  (`play.fill`). Resume variant: `▶ ━━━─── 33 min` with an inline 40×4 progress capsule.
  Hover: brighten/scale 1.02; press: 0.97.
- Secondary circle: 40 pt dark glass (`.glassEffect(.regular.interactive(), in: .circle)`) with
  `plus` → morphs to `checkmark` with a symbol replace transition when added to Ma liste.
- Glass toolbar circles: 32 pt.

### Hero (Home / Films / Séries / Apple TV tab)
- Height ≈ 55 % of window height (min 380, max 620) on Home; ≈ 78 % (min 460, max 760) on detail.
- Full-bleed artwork, `scaledToFill`, slow Ken Burns (scale 1.0 → 1.06 over 12 s, ease-in-out).
- Left-to-right black gradient (0.75 → 0 at 60 % width) + bottom gradient fading into the page
  background. Content block bottom-left at margin 40, bottom padding 56.
- Carousel: auto-advance every 8 s (pause on hover), cross-fade 0.8 s + slight parallax; page dots
  centered at bottom (6 pt, active white, inactive white 35 %, edge dots shrink); thin chevrons
  `‹ ›` at left/right edges, appear on hover.
- Optional label pill above title: `Nouveau`, `Ajouté récemment`, `En direct` (10 semibold, capsule,
  white 15 % bg, white stroke 30 %).

### Cards & shelves
- Shelf = header + horizontal `ScrollView` + `LazyHStack(spacing: 20)`, content margin 40,
  `.scrollTargetBehavior(.viewAligned)`, macOS hover-revealed paging chevrons at the shelf edges
  (glass circles 28 pt) that scroll by a page with animation.
- Wide card (Continue watching / episodes / channels): 16:9, width 260 (episode 280), radius 12.
  Bottom overlay: gradient (black 0 → 70 %), caption 12 semibold, progress capsule (width 28,
  height 3, white on white 30 %), trailing `ellipsis` button (context menu).
- Poster card: 2:3, width 150, radius 10, 1 pt inner stroke white 8 %. Optional title below (13
  semibold) + subtitle (11 secondary) only in grids.
- Ranked card (Top 10): poster with a large white number (64 heavy, tracking −2) at top-left inside.
- Category tile: 2:3 width 150 (or 16:10 for genres), gradient colour from artwork, title bottom-left 15 bold.
- Hover: scale 1.04 + shadow (radius 18, y 10, black 35 %), spring (response 0.3, damping 0.8);
  press: 0.97. Focus ring disabled; the hover lift is the affordance.
- Placeholder: deterministic gradient from the title hash + monogram, then fade-in (0.25 s)
  when the image decodes.

### Detail page (film / série) — Apple TV layout adapted to IPTV
1. Hero (backdrop or blurred-extended poster) with: optional title logo (TMDB) else hero title text,
   metadata line, plot + `PLUS`, tech line + badges (quality, languages, catch-up…), primary button
   (`Lecture` / `Reprendre` with progress / `Lire S1, É3`), circle `+` (Ma liste), and a
   **source button** (capsule glass: `[tint dot] Source A · 4K ⌄`) opening the variant picker when
   several variants exist. Right side: `Avec <cast>` and `Réalisation <director>` 13 pt (secondary
   label + primary names).
2. Séries: season picker `Saison 1 ⌃⌄` (Menu) + episode shelf (episode cards with still, `ÉPISODE n`,
   title, 3-line synopsis, duration, progress, watched checkmark, `…` menu).
3. **Comment regarder ?** → list of source cards (one per variant: source monogram tile 56 pt,
   source name 15 semibold, `4K · VF · MKV` secondary, selected = checkmark). Selecting sets the
   variant used by the Play button (remembered per title).
4. Shelves: `Bandes-annonces` (if trailer), `Dans la même catégorie`, `Distribution` (circular 96 pt
   portraits or monograms, name 12 semibold, role 11 secondary).
5. `À propos` card (rounded 12, secondary fill): title 17 bold, genres caps 10 semibold, plot.
6. Three info columns: `Informations` (Sortie, Durée, Genre, Note, Pays), `Technique` (Vidéo, Audio,
   Conteneur, Débit), `Source` (Fournisseur, Catégorie, Ajouté le).

### Live TV
- `TV en direct`: category capsule chips (glass) + channel grid of 16:9 tiles (logo centered on a
  colour-sampled gradient, now-playing title, progress bar, `EN DIRECT`), plus a **Guide** mode:
  timeline grid (channel column 220 with logo + name + number, 30-min ticks, programme blocks
  radius 8 with title/time, current time vertical line in accent, `Maintenant` button).

### Player (separate window, replicates Apple TV Mac player)
- Black window, controls auto-hide after 3 s of inactivity (fade 0.25 s), cursor hidden too.
- Top-left glass capsule: PiP (`pip.enter`), AirPlay (`airplayvideo`), share. Top-right glass capsule:
  volume slider (width 110) + `speaker.wave.2.fill`. Top-center: dim title of the current subtitle/
  programme.
- Center: `gobackward.10` (44 circle glass), play/pause (64 circle glass), `goforward.10` (44).
- Bottom-left: title 22 bold (+ subtitle line). Bottom-right glass capsule: subtitles
  (`captions.bubble`), audio (`waveform`), speed (`gauge.with.dots.needle.67percent`) menus
  (sections: `Sous-titres` Activés/Non, Langue ▸, Style ▸ ; `Audio` tracks ; `Vitesse`).
- Bottom: full-width glass capsule scrubber, height 28: elapsed `00:27` (11 medium mono digits)
  leading, remaining `-02:09` trailing, track 4 pt, knob 14 pt white with shadow, hover preview time.
- Live: `EN DIRECT` badge instead of remaining time, programme progress, channel up/down zapping,
  channel list panel (glass, slides from the trailing edge), source switch menu, auto-fallback.
- Keyboard: space play/pause, ←/→ ±10 s, ↑/↓ volume (live: channel ±), F fullscreen, M mute,
  Esc exit fullscreen / close panels, S subtitles.

### Onboarding (first launch)
1. Intro: animated tilted poster wall (procedural MeshGradient "posters" drifting diagonally,
   −12° rotation, perspective) under a dark vignette; the Prism logo assembles (prism refraction
   layers + play glyph, spring) then the wordmark fades in; headline + white `Commencer` capsule.
2. `Bienvenue dans Prism` sheet (Apple "Welcome to Apple TV" style): 3 rows with blue SF Symbols
   (TV en direct / Films et séries / Toutes vos sources), footnote privacy text, wide blue `Continuer`.
3. Add source: three glass choice cards (Xtream Codes, URL M3U, Fichier M3U) → form (fields with
   inline validation, optional EPG URL, advanced: User-Agent) → `Se connecter`.
4. Import: animated checklist with live counters (`Chaînes 12 453`, `Films 8 230`, `Séries 1 204`,
   `Guide TV`) and a ring/linear progress; then `Tout est prêt` → zoom/blur transition into Home.
5. `Essayer la démo` link loads the bundled demo source.

### Motion
- Default spring: `.smooth(duration: 0.35)`; hover: `.spring(response: 0.3, dampingFraction: 0.8)`;
  hero cross-fade 0.8 s ease-in-out; symbol changes with `.contentTransition(.symbolEffect(.replace))`.
- 120 Hz friendly: animate only transforms/opacity; avoid animating layout of large containers.

### Colours
- Follows system appearance (Light/Dark) for page backgrounds like Apple TV Mac; hero zones are
  always dark. Accent: system blue. Secondary fills: `.quaternary`/`.fill.secondary`.
- Source tints map `SourceTint` → blue, purple, pink, red, orange, yellow, green, teal.
